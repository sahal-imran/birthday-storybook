# Contributing

Install Node.js 22 LTS, run `npm ci`, and start with `npm run dev`. Keep changes focused and describe their purpose and validation in your pull request.

Use generic sample content and labeled image placeholders. Never include private messages, photographs, credentials, or personal identifying details. Keep personalization in `data/birthday.ts` and document any new configuration or dependency.

Run `npm run typecheck` and `npm run build`. Manually check the changed interactions with keyboard and touch, reduced motion, and phone/desktop layouts. Include relevant verification results in the pull request. There is no lint script configured.

Report bugs with reproduction steps, browser/version, viewport size, and expected versus actual behavior. Do not include private content in reports or screenshots.
